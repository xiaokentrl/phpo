## §A 画像 F 断网全链路端到端验收（T608a）

**落点**：`test/integration/m6_offline_live_test.go`（PHPO_LIVE 守护，默认 skip，仅编译核查）。
**覆盖链路**：装机 → 装服务 → 装扩展 → 建站 → 切版本 → 备份 → **断网重装** → 恢复。

| 步 | 动作 | 关键断言 |
|----|------|---------|
| 1 | 向导 `HomeEnsure`（T607） | 落库 `env.PHPO_HOME` + `Snapshot.DirReady["PHPO_HOME"]==true`（硬红线 4） |
| 2 | 在线首装 nginx/php | 未命中缓存必发 `cache:miss` + `cache:promote`（装前必查→未命中走网络→提升） |
| 3 | 扩展 opcache（T601） | 容器内 `php -m` 含 opcache；临时目录 `~/phpo/php/8.3/ext` **必已清空**；固化镜像存在 |
| 4 | 建站（T403/T405） | vhost 上游精确 `set $php_upstream php-8.3-fpm:9000;`（硬红线 1） |
| 5 | 切版本 8.3→8.1 | 上游改指 `php-8.1-fpm:9000` 且 **无 8.3 残留**（硬红线 1） |
| 6 | 备份（T602） | 归档落盘 + 顶层内容组 `Items>0` |
| 7 | **断网重装（核心）** | 卸容器 + `docker rmi` 基镜像后重装：断言 `cache:hit` **且绝无 `cache:miss`** → 零外网证据 |
| 8 | 恢复（T602） | 异机口径重建后 `List()` 仍含该备份 |

**状态**：编译 + `go vet` + 默认 skip 执行全绿。第 7 步「抹本地基镜像后仅凭缓存 load」将零外网断言做成了排他路径（无网络回退可能），比纯事件断言更强。真实端到端需本机 Docker + `PHPO_LIVE=1` 由用户实跑（不在共享守护进程上执行）。
