## 改动 5（新增条文，建议）

> 48. **禁止在引擎层用短名调用镜像命令**：podman 的 compat 套接字与 CLI 对短名解析不保证一致（各自跟随所在环境的 registries.conf），短名 pull 成功而 save 找不到的怪失败即源于此。所有镜像 save/pull/inspect 的引用一律先过 `QualifyImageRef` 补全为完全限定名；新入口照此办理。

**背景**：0.1.148 期 mysql:5.7 实测——短名 pull「成功」后 CLI save 报 image not known，真错被遮蔽；修复见 `internal/engine/image.go` 的 `QualifyImageRef`（13 用例锁死）。
