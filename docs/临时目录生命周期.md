# 临时目录生命周期

> 对应 AGENTS.md §5.14.4 / §1.13 / 硬红线 8 / §0.2-21 / 工单 T704。临时目录是缓存机制防污染的关键：**单任务存活、四时机必清**。冲突以 AGENTS.md 为准。

## 1. 路径（§5.14.2，固定）

```
~/phpo/{kind}/{version}/ext/
├── apk/     # 编译期间临时存放
└── pecl/
```

`Env.TempExtDir(kind, version)` / `TempExtTypeDir(kind, version, extType)`（`config/offline.go`）；Windows `%USERPROFILE%\phpo\{kind}\{version}\ext\`（§8）。

## 2. 四类必清时机（§5.14.4 / §5.14.12）

| 时机 | reason | 触发方 |
|------|--------|--------|
| 编译成功后 | `compile_success` | `PromoteExtension` 之后 |
| 编译失败后 | `compile_failed` | 扩展编译错误分支 |
| 任务取消后 | `cancelled` | 取消流程（[任务取消语义](./任务取消语义.md) §5） |
| 应用启动时 | `startup_scan` | `app/lifecycle.go` Startup 扫描残留 |

目的：防止残留污染下次使用（§0.2-21）。

## 3. 生命周期表（§5.14.4）

| 阶段 | 行为 |
|------|------|
| 任务开始 | 清空临时目录（若存在上次残留） |
| 下载中 | 下载到 `ext/{type}/` |
| 编译中 | 从 `ext/{type}/` 读取 |
| 编译成功 | 文件 mv 到 `offline/` 缓存 → 清空 `ext/` |
| 编译失败 | 清空 `ext/` |
| 任务取消 | 清空 `ext/` |
| 任务结束 | 临时目录必然不存在 |
| 应用启动 | 扫描并清空所有残留 |

## 4. 实现（`internal/cache/tempdir.go`）

```go
EnsureTempDir(kind, version)            // 建 ext/
EnsureTypeDir(kind, version, extType)   // 建 ext/{apk|pecl}
ClearTempDir(ctx, kind, version, reason) // = clearDir
clearDir(path, reason):
    Stat → IsNotExist 视为已清空（仍发射事件，幂等）
    否则 RemoveAll(path) → Emit("cache:tempdir-cleared", {path, reason})
```

对应 §5.14.4 的 `ClearTempDir` 参考实现（不存在即 no-op）。

## 5. 事件

每次清空发射 `cache:tempdir-cleared { path, reason }`（`model.CacheTempdirClearedEvent`）；前端 `cacheStore` 据此更新展示，并可用于审计/日志抽屉。

## 6. 禁止（§1.13.4 / §5.14.12）

- ❌ 临时目录跨任务持久化。
- ❌ 编译成功/失败后保留临时目录。
- ❌ 任务取消后不清临时目录。
- ❌ 应用启动时不扫描残留。
- ❌ 静默跳过（清空必发事件）。
