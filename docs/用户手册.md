# 用户手册

> 面向 phpo 使用者的操作手册；功能边界以 AGENTS.md 为准，界面细节见 [界面规格](./界面规格.md)，可调用能力见 [接口契约](./接口契约.md)。phpo 是面向 PHP 开发者的本地 Docker 化开发环境管理器，**仅提供 GUI，无 CLI**。

## 1. 前置条件

- 已安装并运行 **Docker**（Windows/macOS：Docker Desktop；Linux：Docker Engine）。Docker 未运行则无法启动服务（硬红线 7）。
- 首次启动进入**装机向导**：设定 `PHPO_HOME`（工作目录根，默认值 `~/phpo`）与 `WWW_ROOT`（站点根，默认值 `~/www`）。此后所有服务配置、数据、日志、备份与离线缓存都落在这两个根之下（文档里记作 `./…`，见 AGENTS.md §0.1.1）；`config.yaml` 与 `phpo.db` 则在系统的应用数据目录里，不随工作目录移动。
  - 向导打开即先**检测工作目录是否已设置**：已设置（两根已写入 `config.yaml` 且目录确实存在）时只回显当前两根与「完成」，不会再让你走一遍设置流程，也不会重复创建任何目录、文件或改写配置。
  - 「验证」是**只读预检**：只检查目录是否存在、上级是否可写，**不创建任何目录或文件**；只有点「确认并创建」（`HomeEnsure`）才会真正创建工作目录子树并落库。
  - 目录设置完成（或检测到已设置）后，phpo **第一件事就是同步权威快照**：主界面与向导弹框在同一时刻归位，无需你手动刷新，也不会出现「弹框说已设置、界面还拦着写操作」的错位。
  - 若本会话已按旧的工作目录完成初始化、刷新快照无法归位（各服务的根目录在启动时展开），phpo 会提示「正在重启应用」并按 `config.yaml` 重新拉起进程；重启过一次仍未就绪则只报错、不再重复重启。
  - 环境诊断里的「PHPO_HOME / WWW_ROOT 可写」同样只读判定：目录不存在只报错，不会顺手替你建出来。

## 2. 安装一个服务

1. 进入对应服务页（PHP / MySQL / PostgreSQL / Redis / Nginx）。
2. 点「安装」，输入版本号（**任意合法字符串**，如 `8.4`、`7.4-apache`；不限字符集，仅防路径穿越）。
3. phpo 先查离线缓存：命中则零网络加载；未命中则先探本机 Docker 镜像库——镜像已在本机就直接导出重建缓存（同样不联网），本机也没有才联网拉取；成功后自动提升到缓存。
4. 安装即启动；卡片显示运行态。状态由后端权威推送，无需手动刷新。

> Nginx 为单例（只能装一个）；PHP 可多版本并存。

## 3. 建站与访问

1. 「站点」页 → 添加站点：填域名（支持 `localhost`、单段名、`.test`/`.dev`/`.local` 等任意后缀）、根目录（可在 WWW_ROOT 外，会警告但放行）、选择 PHP 版本、端口。弹窗在「站点目录」下方实时回显两行宿主绝对路径：站点根目录（含容器路径）与 **vhost 文件路径** `{NGINX_SITES_ROOT}/{域名}.conf`。
2. 端口默认 80，可手动指定任意端口。**新建站点**时端口若已被占用：**不会改你填的端口**，只弹框提示，站点照常创建但处于降级态（暂不写 vhost、暂不发布端口）；腾出该端口或之后改一次端口即自动生效。**改已有站点**的端口时，占用才会自动顺延到 1–65535 首个可用端口（不报错）。
3. **建站的唯一服务门禁是 Nginx 已安装**：没装 Nginx 时无法建站（没有 nginx 就发布不了站点）。除此之外都不阻断：Nginx 已装但未运行、没装 PHP、端口被占用，都只弹框告警，站点照常创建（落库 + 站点目录 + hosts），仅暂不写 vhost、暂不发布端口。降级站点会在这些事件后**自动补齐**（`ReconcileServe`：补写缺失的 vhost → reload → 重发布端口）：安装/重建/启动 Nginx、安装或重建 PHP 版本、卸载让出端口的 MySQL/PostgreSQL/Redis、删除站点或改端口腾出端口。**Nginx 停着的时候改站点不会把它偷偷启动**——那是你主动关掉的服务；这段时间站点保持降级，等你启动 Nginx 后再一次补齐（顺带校对宿主端口，把容器上已无人使用的旧绑定一并收掉）。
4. 建站成功后立刻拉取权威快照，新站点当场出现在列表里（不等事件时序）。
5. 就绪时建站会写 vhost（写前 `nginx -t` 必过）、加 hosts、发布端口到 nginx 容器；失败自动回滚。
6. 切 PHP 版本：站点行内下拉选择，上游精确指向 `php-{版本}-fpm:9000`，切换即时生效（reload nginx）；Nginx 在运行时，降级站点也会借此补写 vhost。**注意：改端口 / 切 PHP / 伪静态 / 手改 vhost 正文这四类编辑都要把新正文写盘，而写盘前的 `nginx -t` 只能在运行中的容器里执行，所以 Nginx 未运行时会被直接拦下并提示「请先启动 Nginx 再重试」**（建站不受此限，未运行只降级）。
7. 伪静态：从 9 种预设选择，或自定义规则；高级用户可手改 vhost 正文。
8. 站点列表的 Hosts 列：已解析到 `127.0.0.1` 时显示「已解析」chip；未解析（如建站时 hosts 不可写、提权被拒）显示「加 hosts」按钮，点了才写系统 hosts。macOS/Windows/Linux 分别经 osascript admin / UAC / polkit 提权；**提权被拒只弹框转达人话警告并给出需手动添加的 `127.0.0.1 {域名}` 一行，不影响站点其他操作**（§5.7 doctor 同口径）。列表里的「健康」列与 Hosts 列都取自后端快照真值，界面不做乐观更新。
9. 编辑本站点 vhost 正文（「修改配置」→ Nginx 配置）：编辑框默认铺到主窗口高度的 80%，右下角可拖拽调整宽高。「保存并重载」先让容器跑 `nginx -t`（硬红线 2）：**校验不过会弹框列出 nginx 报错原文，线上配置已自动回滚、未重载，你的草稿仍留在编辑框里**，改完可直接再保存；ESC 只关报错弹框，不会关掉编辑器。
10. 删除站点会顺带**回收该域名的 hosts 条目**（不留指向已删站点的孤儿解析）。与建站同口径：提权被拒或 hosts 不可写时**只警告、站点照常删除**，任务日志里给出需手动删除的 `127.0.0.1 {域名}` 一行；删除任务失败回滚时条目会被重新加回。
11. **有任务在跑时站点行会标出来**：被操作的那一行在「健康」旁再显示「运行中… {步数}/{总步数}」（改端口、切 PHP、伪静态、删站、加 hosts…）或「排队中」，与服务卡片同一口径。操作按钮**不会被禁用**——写操作按 FIFO 排队执行。**新建站点不点亮**：站点还没进列表（快照里没有这一行），进度看建站弹窗与日志抽屉。

## 4. 数据服务与密码

- 为 MySQL / PostgreSQL / Redis 设置**密码**：明文存储，默认 `123456`，可改、**可留空**、长度不限，UI 用 👁 查看 / 📋 复制 / ↺ 重置。**不校验**密码强度。
- 改服务端口：服务端口若被占用会报错（服务端口不自动顺延），请换一个。
- **端口与密码改完不会立刻进到正在跑的服务里**：Docker 的宿主端口发布与密码 `env` 都只在**建容器那一刻**落定，`停止`/`启动` 改不动已建好的容器。所以凡有宿主端口的服务（MySQL/PostgreSQL/Redis/**Nginx**）的版本卡片上都有「**重建生效**」按钮：它按你新存的配置重建该版本容器（等效于「卸载但保留数据卷 → 复用卷重装」），点完端口与密码才真正切换。保存端口/密码后的提示条也会告诉你要点它。
- **端口行显示的是权威值**：没改过端口时卡片显示该服务的默认宿主端口（mysql 3306 / pgsql 5432 / redis 6379 / nginx 80），与容器实际绑定的端口同源；php 不发布宿主端口（只在 `phpo-network` 内可达），该行留空。安装弹窗里按版本号顺手预填的 `33xx` 只是**预填建议**，不是你未改过时的真值。
- **有任务在跑时卡片会标出来**：被操作的那一版显示「运行中… {步数}/{总步数}」，排队中的显示「排队中」。操作按钮**不会**被禁用——写操作按 FIFO 排队执行，你可以继续点下一个。
  - 重建前会先判端口占用：**新端口被别的 service 占着就整次拒绝，正在运行的容器一根手指都没动**（不会先删了再失败）。
  - 数据卷与宿主目录（`./{kind}/{version}/data` 等）全部保留，不丢数据；重建期间该版本会短暂停止，连着它的应用会断线。
- 卸载服务默认**保留数据卷**；重装复用卷，数据不丢。

## 5. 备份与恢复

- 「备份」页：一键创建备份（暂停数据服务 → 导出快照 → 打包 → 自动重启）。
- 支持下载归档（原生保存框选路径）、恢复（清空命名空间 → 解包 → 重建容器）、删除（二次确认）。
- 备份包含站点数据、配置、离线缓存与明文凭据——请当作敏感文件妥善保管。

## 6. 离线缓存管理

- 「离线缓存」页查看：总占用、条目数、每项镜像/apk/pecl、校验状态。
- 「全部校验」重算 SHA256；损坏会提示并转入未命中分支（先探本机镜像库，再决定是否联网）。
- 清理三模式：保守（仅损坏）/ 标准（+久未使用）/ 激进（+全部，在用受保护，涉删二次确认）。
- 换机/内网：拷贝 PHPO_HOME 根下的 `./offline/`（根位置由装机向导决定，可在向导「已设置」回显或快照 `env.PHPO_HOME` 查看）即可让另一台机器零网络安装。

## 7. Docker 清洁与回收站

- 「清理」页：扫描孤儿资源（容器/卷/网络/镜像），按三模式清理。
- 回收站：删除的站点根目录保留 **7 天**，可一键恢复；到期后彻底删除。
- 操作审计：设置页可查最近操作历史（`<用户数据目录>/logs/operations.log`（Linux `~/.config/phpo/logs/`））。

## 8. 诊断（doctor）

- 「总览」页 doctor 一键体检 15 项：Docker 可用/版本、端口、目录可写、hosts 权限、网络、缓存完整性、临时目录残留等。
- 可修复项提供一键操作：状态校准（`calibrate`）、清空临时目录残留（`clear_temp`）。多数非致命问题以**警告**呈现，不阻断使用（最小限制原则）。

## 9. 检查更新与升级

- 启动时 + 每 24 小时自动检查更新，也可在设置里手动检查。
- 有新版本时弹窗提示；升级包经 SHA256 + 数字签名双校验后安装，失败自动回滚到旧版本。

## 10. 外观与偏好

- 6 套主题、中/英双语、7 档界面缩放；这些偏好只存本机（`localStorage`），不影响后端状态。
- 命令面板（20 条命令）与系统托盘提供快捷操作；日志抽屉显示等效命令仅为**展示**，不可执行。
- 设置页的「显示托盘图标」「关闭窗口时最小化到托盘」即时生效：两者都勾选时，点窗口关闭按钮只是收进托盘（点托盘图标唤回）；关掉任一项，点关闭即退出应用。「显示托盘图标」在 Linux 上只影响驻留判断与窗口内托盘，撤下系统图标的这一步 Wails 当前版本尚未支持。

## 11. 常见问题

| 现象 | 处理 |
|------|------|
| 启动报「服务尚未初始化」 | 等待初始化完成或先走装机向导 |
| 已有任务运行中 | 排队或点「取消」（取消会回滚并清临时目录） |
| 端口被占 | 新建站点：仅提示，站点以降级态创建（暂不发布端口），腾出端口或改一次端口即恢复；改站点端口：自动顺延；服务端口：换值重试 |
| 装不上（内网/断网） | 确认对应版本已在离线缓存中；未缓存的离线环境无法安装 |
| 想彻底重来 | 清理页激进清理（保留卷）或删卷前二次确认 |
