# 域名策略

> 对应 AGENTS.md §1.11 / §5.11 / §0.2-15 / §2.1（排除「域名格式严格校验」）/ 工单 T704。域名遵循最小限制原则：**允许绝大多数字符**，仅拦截会破坏 vhost/hosts 的空值与明显非法结构。冲突以 AGENTS.md 为准。

## 1. 允许清单（§5.11 / §1.11）

- `localhost`、单段名（无点，如 `myapp`）。
- `.local`、`.dev`、`.test` 等任意后缀。
- 泛域名（`*.demo.test` 形态在 vhost `server_name` 层支持）。
- 多域名（一个站点绑定多个 `server_name`）。
- IDN / 国际化域名（以punycode/UTF-8 形式录入，落 hosts 与 vhost）。

## 2. 唯一实现层校验（`config.ValidateDomain`）

`internal/config/validate.go`：

1. `strings.ToLower(strings.TrimSpace(domain))`（小写化 + trim）。
2. 非空且 `len ≤ 253`（DNS 标签总长常识上限）。
3. 标签正则：`^[a-z0-9]([a-z0-9-]*[a-z0-9])?(\.[a-z0-9]([a-z0-9-]*[a-z0-9])?)*$`——允许字母/数字/连字符，段间以 `.` 分隔；不含空段、不以连字符起止。
4. 失败文案 `errs.DomainInvalid`（人话提示，§3.2 原则 3）。

> 该正则是「防破坏」而非「白名单限制」：放行单段名与任意后缀，仅拒空段/非法分隔。产品层不对可注册 TLD 或长度作额外限制（§0.2-15）。

## 3. 落地链路

- 建站：`SiteAdd(AddInput{Domain,...})` → preflight `site-add`（查重 `errs.DomainExists`）→ 写 vhost `server_name`（硬红线 2：`nginx -t` 必过）→ 加 hosts（提权，`vhost/hosts/`）。
- 映射：`derivePaths`（`config/paths.go`）由域名派生站点目录/ vhost 文件名；含点/连字符安全，穿越由路径校验兜底（与 `docs/路径策略.md` 一致）。
- 多域名：主域名入 `Site.Domain`（唯一键），额外别名写入 vhost `server_name` 正文，vhost 手改标记 `VhostCustomized`（见 [领域模型](./领域模型.md) §2）。

## 4. 明确不做

- ❌ 强制要求已注册公网域名。
- ❌ 限制后缀集合（`.dev`/`.local`/单段名合法）。
- ❌ 前端本地乐观放行/拦截作为最终裁决（UI 即时校验 + 后端 preflight 权威，§0.2-14）。
