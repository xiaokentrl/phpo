# 缓存清单规范

> 对应 AGENTS.md §5.14.2（manifest.json 结构）/ §0.3（schema_version=1 · SHA256 · 缓存条目无上限）/ 工单 T704。定义每个离线缓存版本目录下的 `manifest.json` 冻结契约。冲突以 AGENTS.md 为准。

## 1. 定位

每个 `./offline/{kind}/{version}/`（`./` = PHPO_HOME 根，装机向导选定，见 AGENTS.md §0.1.1）下有且仅有一份 `manifest.json`，记录该版本缓存的图片/扩展条目及其 **SHA256**，是「命中即校验、损坏即回退」的数据依据。读写在 `internal/cache/manifest.go`。

## 2. 结构（§5.14.2，snake_case 冻结契约）

```json
{
  "schema_version": 1,
  "kind": "php",
  "version": "8.4",
  "created_at": "2026-09-18T12:00:00Z",
  "updated_at": "2026-09-18T14:30:00Z",
  "image": { "name": "php:8.4-fpm", "digest": "sha256:...", "size": 450000000, "sha256": "...", "cached_at": "..." },
  "apk":  [ { "name": "libzip-1.10.1.apk", "sha256": "...", "size": 123456, "cached_at": "..." } ],
  "pecl": [ { "name": "redis-6.0.2.tgz",   "sha256": "...", "size": 234567, "cached_at": "..." } ]
}
```

Go 结构体（`internal/model/cache_entry.go`）：

| 类型 | 字段（JSON 标签） |
|------|------------------|
| `CacheManifest` | `schema_version, kind, version, created_at, updated_at, image?, apk[], pecl[]` |
| `ManifestImage` | `name, digest, size, sha256, cached_at` |
| `ManifestPackage` | `name, sha256, size, cached_at` |

## 3. 字段约束

- `schema_version`：**固定 1**（`manifest.SchemaVersion`）；未来演进须升版本并保留兼容读。
- `image` 可空（`omitempty`，扩展-only 缓存无镜像）；`apk`/`pecl` 仅 php 类缓存有。
- `sha256`：小写 hex，对文件字节计算；校验用 `crypto/sha256`（`cache/verifier.go`）。
- 时间戳：RFC3339 UTC。
- 缓存条目数：**无上限**（§0.3），用户可手动清理。

## 4. 读写语义（`manifest.go`）

- `LoadManifest(kind, version)`：不存在返回可继续（视为空清单），存在则反序列化。
- `SaveManifest(mf)`：**原子写**到 `{kind}/{version}/manifest.json`（临时文件 + rename），`newManifest` 自动填 `SchemaVersion=1` 与时间戳。
- `PromoteImage` 写/更新 `manifest.image`；`PromoteExtension` 经 `upsertPackage` 追加/去重 `apk`/`pecl` 条目。

## 5. 校验与损坏处理（§5.14.5）

| 时机 | 动作 |
|------|------|
| 命中前（`LookupImage`/`LookupExtension`） | `FileSHA256` 比对 manifest 记录值 |
| 提升时 | 计算并写入 manifest |
| 定期扫描 / `OfflineVerifyAll` | 逐文件重校验，失败 `VerifyResult{ok:false, failed[]}` |

校验不符 → 标记损坏 → `cache:corrupted { kind, version, entry }` → 落入未命中分支（镜像先探本机镜像库，再决定是否联网）；禁止使用损坏缓存（§5.14.12）。

## 6. 静态对账

`scripts/check-cache-manifest.go`（`//go:build ignore`）解析 `cache_entry.go`，断言三结构体 JSON 标签键集与本规范一致（`task check` 门禁之一），防止契约漂移。

## 7. 缓存统计（`cache/stats.go` → `model.CacheStats`）

`totalBytes / entryCount / imageCount / extCount / corrupted`，供 OfflineView 展示总占用与损坏计数（§5.14.7）。
