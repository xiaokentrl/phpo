# 跨平台差异

> 对应 AGENTS.md §8（跨平台差异矩阵）/ §4.2（运行时目录）/ 工单 T704。三平台（Windows / macOS / Linux）行为差异的权威表；落地代码见括注。冲突以 AGENTS.md 为准。

## 1. 差异矩阵（§8）

| 差异维度 | Windows | macOS | Linux |
|---------|---------|-------|-------|
| Docker 运行时 | Docker Desktop（WSL2） | Docker Desktop | 原生 Docker Engine |
| 挂载性能 | ⚠️ VM 转发，慢 | ⚠️ VM 转发，慢 | ✅ 原生 |
| 端口 80 | ✅ 无需特权 | ⚠️ 需 root/setcap | ⚠️ 需 root/CAP |
| hosts 提权 | UAC | osascript admin | polkit |
| 用户数据目录 | `%APPDATA%\phpo\` | `~/Library/Application Support/phpo/` | `~/.config/phpo/` |
| 路径解析 | ⚠️ 无 `~` | ✅ | ✅ |
| 路径大小写 | 不敏感 | 默认不敏感 | 敏感 |
| 系统托盘 | ✅ | ✅ | ⚠️ 需 libappindicator |
| 代码签名 | EV 证书 | Developer ID + 公证 | 无 |
| `config.yaml` 权限 | NTFS ACL | `chmod 600` | `chmod 600` |
| 升级安装方式 | NSIS 静默安装 | .app 替换 | AppImage 替换 |
| 缓存路径 | `%USERPROFILE%\phpo\offline\` | `~/phpo/offline/` | `~/phpo/offline/` |
| 缓存文件权限 | NTFS ACL | `chmod 644` | `chmod 644` |
| 临时目录 | `%USERPROFILE%\phpo\{kind}\{version}\ext\` | `~/phpo/{kind}/{version}/ext/` | `~/phpo/{kind}/{version}/ext/` |

### 2.1 hosts 提权的三平台统一口径

`hosts.Manager` 先直写；直写遇 `os.ErrPermission` 才调平台提权器重写整份文件。**两条被拒路径都降级为人话 `Warning`（`error` 返回 `nil`），绝不把 polkit / UAC / osascript 的原始错误抛给 UI**：

| 场景 | Warning 口径 |
|------|-------------|
| 直写被拒且本平台无提权器（如测试用 `NewAt`） | 「无法修改 hosts（{路径}）。请以管理员身份运行后手动添加：127.0.0.1 {域名}」 |
| 提权器返回错误（用户在系统弹窗里点了取消） | 「提权写入 hosts 失败（{路径}）：{原因}。请以管理员身份运行后手动添加：127.0.0.1 {域名}」 |

两者均与 §5.7 doctor 的「hosts 可写」建议同口径；调用方（建站 / 站点列表「加 hosts」）只提示不阻断。真正的文件 IO 失败（读不了、磁盘错）仍照常返回 `error`。单测：`TestManager_Elevate`（非 root 下 `chmod 0444` 造不可写）。

## 3. 路径与大小写注意事项

- **无 `~` 展开（Windows）**：`derivePaths`（`internal/config/paths.go`）须用绝对路径；不得依赖 shell `~`。
- **大小写**：Linux 敏感，容器/卷命名、缓存目录 key 全小写常量（`phpo-{kind}-{version}`，§5.13.2）；跨平台迁移备份时保持小写标识。
- **路径分隔**：统一用 `filepath.Join`，模板/配置正文内路径写 `/`（nginx/容器内为 Linux 视图）。
- **路径穿越防御（硬红线 3）**：`..` / `\x00` / 绝对性校验三平台一致，不因大小写放松。

## 4. 端口与特权

- 站点端口默认 80：Windows 免特权直绑；macOS/Linux 需 root/setcap/CAP_NET_BIND_SERVICE。新建站点端口冲突**不顺延**（告警 + 降级建站），因此不可绑 80 时由用户自行换端口（§5.8，**不报错、不改用户所填端口**）。
- 改已有站点的端口：占用才顺延 1–65535 首个可用（三平台一致，**不报错**）。
- 服务端口（安装/改配置）占用：三平台一致报 `portInUse`，不自动顺延。
- 探测实现：`pkg/port/probe.go`（listen 探测）+ `sequence.go`（1–65535 顺延，无窗口上限）。

## 5. 托盘与 GUI

- 仅 GUI，无 CLI（§0.2-4 / §5.1）；三平台均经 `internal/ui/tray.go`。
- Linux 托盘依赖 `libappindicator`（`build/linux/nfpm.yaml` 已声明依赖），缺失时降级为窗口常驻，不阻断启动。

## 6. 权限模型（密码/文件）

- 密码明文（`config.yaml`，位于各平台 XDG 用户配置目录内 `phpo` 子目录），三平台一致**零校验零加密**（§5.2）；`config.yaml` 权限 mac/linux `chmod 600`，Windows 靠 NTFS ACL。
- 缓存文件 `chmod 644`（可跨用户读，但仍在用户 HOME 下）。

## 7. 升级安装差异

| 平台 | 机制 | 校验 |
|------|------|------|
| Windows | NSIS `/S` 静默安装 | SHA256 + Ed25519（硬红线 6） |
| macOS | 替换 `.app` bundle | 同上 |
| Linux | 替换 AppImage / 包管理器 | 同上 |

失败自动回滚：`internal/updater/rollback.go`（marker + 下次启动自动回滚），三平台共用。
