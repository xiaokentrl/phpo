# 界面规格

> 对应 AGENTS.md §0.3（UI 权威数）/ §1.2（原型资产）/ §4.1（frontend/src）/ 工单 T704。本文以 SSOT 单文件原型为规格来源，并记录生产 Vue 落地的对应结构；数字冲突一律以 AGENTS.md §0.3 为准。

## 1. 唯一界面来源

`前端唯一界面来源.txt`（约 2500 行单文件原型：CSS ~370 / HTML ~70 / JS ~2060）是前端**唯一**界面来源（§0 顶部声明）。生产版按其 1:1 迁移领域模型、校验层与视图结构；`index.html` = `tail -n +4` 上者，须与 SSOT 同步。

## 2. UI 权威数（§0.3，禁止漂移）

| 维度 | 权威值 | 原型来源 |
|------|-------|---------|
| 路由数 / 渲染函数数 | **10 / 6** | `NAV` / `VIEWS` |
| SVC_META 服务数 | **5** | `SVC_META` |
| MOUNTS 挂载表数 | **5** | `MOUNTS` |
| REWRITE_PRESETS 数 | **9** | `REWRITE_PRESETS` |
| DEFAULT_CONFIGS | **5 服务 7 文件** | `DEFAULT_CONFIGS` |
| THEMES 数 | **6** | `THEMES` |

| MESSAGES 键数 | **约 300+** | `MESSAGES['zh-CN']` |
| UI_SCALE 档位数 | **7** | `UI_SCALE.snap` |
| 日志行类型 | **5** | cmd/meta/ok/dim/err |
| 任务状态 | **4** | running/success/failed/cancelled |
| 模态数 | **12** | 见 §5 |

## 3. 导航与视图（10 屏）

原型 `NAV` 十条路由 → 生产 `frontend/src/views/` 视图：

| 路由 name | 视图 | 说明 |
|-----------|------|------|
| `sites` | `SitesView.vue` | 站点列表 + 建站/端口/PHP 切换/伪静态 |
| `php` | `PhpView.vue` | PHP 版本全生命周期 + 扩展 |
| `mysql` / `pgsql` / `redis` / `nginx` | `MysqlView.vue` 等 | 各服务卡片（SVC_META 5 服务） |
| `backup` | `BackupView.vue` | 备份/恢复/下载 |
| `offline` | `OfflineView.vue` | 离线缓存总览（原 `renderOffline()` 真数据化） |
| `overview` | `OverviewView.vue` | 总览 + doctor 入口 |
| `settings` | `SettingsView.vue` | 主题/语言/缩放/工作目录/审计入口 |

> 生产在原型 10 屏基础上增设 `CleanupView.vue`（Docker 清洁，M6）与 `ServiceView.vue`（服务通用外壳），故 `views/` 目录实为 12 文件、`router/index.ts` 注册 11 条命名路由。**§0.3 的「10/6」指原型 `NAV`/`VIEWS` 计数**，生产扩展不改动该权威值。

## 4. 服务视图与挂载

- 5 服务卡片元数据来自 `SVC_META`（图标、默认版本建议 `suggested`、端口）。版本建议落 `configs/versions.json`（目标），当前由 `internal/config/versions.go` 提供。
- `MOUNTS`（5 类挂载）→ `internal/engine/mount.go` + 前端 `MountList.vue`。
- `DEFAULT_CONFIGS`（5 服务 7 文件）→ `internal/template/templates/*.tmpl`，经 `check-templates.go` 对账。

## 5. 模态（12）与业务组件

`frontend/src/components/business/`（生产实有 17 个业务/模态组件，核心 12 模态）：

`InstallModal` `SiteAddModal` `SiteConfigModal` `ConfigModal` `PhpExtensionsModal` `RewriteModal` `ThemePickerModal` `HomeSetupWizard` `DangerConfirm` `UpdateModal` `CleanupModal` `CacheCleanupModal`；另含 `CacheDetailModal` `TrashViewer` `CmdPalette` `TaskDrawer` `AppTrayMenu`。

- 所有模态外壳 + 即时校验（前端 `utils/validate.ts` 复刻原型 validators），最终裁决仍在后端 preflight（§0.2-14）。
- 危险操作（删卷、激进清理）走 `DangerConfirm` 二次确认（§5.13）。

## 6. 命令面板 / 托盘 / 日志抽屉

- `CmdPalette.vue`：`CMD_ITEMS` **20** 条命令（§0.3）。
- `AppTrayMenu.vue` + `internal/ui/tray.go`/`menu.go`：原生托盘；`ui:command` 本地广播联动（不属于 17 协议事件）。
- `TaskDrawer.vue`：订阅 `task:log/progress/done`，按 5 类日志行渲染；`等效命令`（`.drawer-cmd`）保留展示但标注「仅展示」、不可执行，复制时 Toast「本产品不提供 CLI」（§1.4）。

## 7. 主题 / 缩放 / i18n（纯前端）

- 6 主题（`styles/themes/`：light/dark 对应 `midnight`/`ocean`/`forest`/`sakura`/`oled` + `index.css` 汇总），由 `prefsStore` 切换，落 `localStorage`（§3.1-5）。
- `UI_SCALE` 7 档位缩放 + `useZoom`/`useResize` 补偿；`layoutStore` 管布局。
- i18n：`locales/zh-CN.ts` + `en-US.ts`（约 300+ 键，从原型 `MESSAGES` 提取），`scripts/check-i18n-keys.go` 对齐校验。后端另有 `pkg/errs` code → 前端 i18n 文案（错误信息是人话，§3.2 原则 3）。

## 8. 状态回流

前端只读 `appState` store（由 `useStateSync` 订阅 `state:changed` 写入），组件不各自订阅、不乐观更新（硬红线 4）。UI 偏好（主题/语言/布局/缩放）例外，留在前端 `localStorage`。
