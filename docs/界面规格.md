### 3.1 站点表列的显示口径（`SitesView.vue`）

| 列 | 口径 |
|----|------|
| PHP 版本 | 下拉项 = 已装 PHP 版本 ∪ 本站点当前版本。站点未选 PHP（降级站点）时渲染 `sites.php.none`（「未选择」）占位项，**不把空值伪装成某个版本**；版本已不在已装列表时追加 `sites.php.uninstalled`（「（未安装）」）后缀。文案一律走 i18n 键，不得硬编码英文。 |
| 健康 | 三态 pill，取值只来自快照 `site.health`（`up`/`warn`/`down` → `sites.health.*`），前端不推断。 |
| Hosts | `site.hosts` 为真显示 `sites.hosts.resolved`（「已解析」）chip；为假显示 `sites.hosts.add`（「加 hosts」）按钮。 |
| 健康（同行的任务指示） | 健康 pill 旁可再亮一枚 `pill-warn`：判据是 `TaskBrief.domain === 本站点域名`（`type` 为站点类任务时后端才带 `domain`），运行中「执行中 {step}/{total}」、排队「等待中」，复用 `task.running` / `task.queued`。**建站不在此列**——新站点在 Apply 之前根本不在快照里，没有行可标，进度由建站弹窗与日志抽屉承载。同服务卡片：只加指示、不禁用按钮。 |

### 3.1.1 站点行的任务指示

站点写链路（`site-remove` / `site-port` / `php-switch` / `rewrite` / `site-vhost` / `site-hosts`，以及 `site-add`）的任务在 `model.TaskMeta` 里已带 `Domain`，经 `briefOf` 透传进 `Snapshot.Tasks`；`SitesView.vue` 的 `busyPill(domain)` 只读这个字段。**不得从 `label` 文案里抓域名**——文案随 i18n 变化，一换语言指示就全丢。

## 4. 服务视图与挂载

- 5 服务卡片元数据来自 `SVC_META`（图标、默认版本建议 `suggested`、端口）。版本建议由 `internal/config/versions.go` 提供（总纲 v2.9.3 起 §4.1 不再列 `configs/` 目录）。
- **卡片上的端口显示只认两个来源**：端口键 `{KIND}_{VER}_PORT`（快照 `env`），键未落库时回落 `SVC_META[kind].defaultPort`——它与后端 `internal/service/registry.go` 的 `Spec.HostPort` 同值（mysql 3306 / pgsql 5432 / redis 6379 / nginx 80 / php 0=不发布），即容器真正发布的端口。**不得用 `suggestPortFor` 显示**：那是安装弹窗的预填算法（mysql 8.4 会算成 3384），拿来显示就成了卡片谎报端口。同一口径也用于站点视图的 nginx 基准端口。
- `MOUNTS`（5 类挂载）→ `internal/engine/mount.go` + 前端 `MountList.vue`。
- `DEFAULT_CONFIGS`（5 服务 7 文件）→ `internal/template/templates/*.tmpl`，经 `check-templates.go` 对账。
- 版本卡片底部按钮：`管理配置` / `停止`↔`启动` / **`重建生效`（凡有宿主端口发布的服务，即 `needsPort(kind)` = mysql/pgsql/redis/nginx）** / `卸载`。「重建生效」是端口与密码改后**唯一**的生效入口（两者只在建容器时落定，`停止`/`启动` 改不动），点击走 `DangerConfirm` 说明「会短暂停止 / 卷与目录保留 / 端口被占即拒绝且不动在跑的容器」→ `update-config` preflight → `Reinstall`。保存端口（`svc.portPending`）与保存密码（`svc.passwordPending`）后的 Toast 都必须把人带到这个按钮，**不得写成已生效**（硬红线 4）。
- **重建的 preflight 不得带 `field:'port'`**：重建不改端口，只该裁「服务在不在 / 装没装」。带上会把当前端口再校验一遍，而端口键未落库时取到空串，必然报「端口格式不正确」——重建按钮就变成一个永远点不动的死路。真正的端口占用预检在后端 `assertHostPortsFree`（Pre-Clean 之前），冲突即拒绝且不碰容器。
- **卡片的任务指示**：`TaskBrief` 带 `kind` / `version`（服务类任务才有），卡片据此在状态 pill 旁再亮一枚 `pill-warn`——运行中显示「执行中 {step}/{total}」，排队显示「等待中」，文案复用 `task.running` / `task.queued`。**只加指示、不禁用按钮**：并发写操作按 FIFO 排队是合法路径（§5.6），拦点击属非必要限制。判据不得改为按 `label` 文案反推（文案要 i18n，一改指示就丢）。
- **密码「重置」的成功提示只在落库返回成功后发**：`PasswordField.persist` 返回 `Promise<boolean>`，`reset()` 据此决定要不要报 `svc.passwordReset`；否则写失败也会弹「已重置」。

## 5. 模态（12）与业务组件

`frontend/src/components/business/`（生产实有 19 个业务/模态组件；下表 12 个是原型的模态集，其余为生产新增）：

`InstallModal` `SiteAddModal` `SiteConfigModal` `ConfigModal` `PhpExtensionsModal` `RewriteModal` `ThemePickerModal` `HomeSetupWizard` `DangerConfirm` `UpdateModal` `CleanupModal` `CacheCleanupModal`；另含 `CacheDetailModal` `CacheImportModal` `TrashViewer` `CmdPalette` `TaskDrawer` `AppTrayMenu` `DockerGate`。

- **`CacheImportModal.vue`（手工导入缓存，AGENTS.md §5.14.9a）**：选 kind / version / 条目类型（`image` / `apk` / `pecl`，后两类仅 php 可选）+ 填源文件路径（「浏览」走原生文件选择器）。提交走 `api/offline.ts#importEntry → App.OfflineImportFile`，经 `submitWrite()` 展开抽屉、由 `cache:promote` 事件回流；**导入是复制**（原件留在原处），不走 `docker load`、不建容器。失败以 `errs` 人话码上抛（如 `FileMissing`＝「待导入的文件不存在」），Toast 与抽屉日志各一份。

- 所有模态外壳 + 即时校验（前端 `utils/validate.ts` 复刻原型 validators），最终裁决仍在后端 preflight（§0.2-14）。
- 危险操作（删卷、激进清理）走 `DangerConfirm` 二次确认（§5.13）。
- `SiteConfigModal`（编辑本站点 nginx vhost 正文）走 `ModalShell` 的 `tall` 变体：默认高度铺到主窗口的 **80%**（`.modal-tall{min-height:80%}`，用百分比而非 `vh` 以随 `zoom` 缩放同步），支持右下角拖拽改宽高（拖拽后显式尺寸接管并放开 CSS min/max，可往小里拖）。「保存并重载」先由后端 `nginx -t` 校验（硬红线 2），**校验未通过以弹框提醒而非 Toast**：错误弹框 `.modal-err`（z-index 160，压在编辑弹窗之上、Toast 之下）列出 nginx 报错原文，草稿保留在编辑器内不丢，ESC 只关错误弹框不关编辑器（§5.10）。
- 站点列表「加 hosts」：调用 `SiteAddHosts`；提权被拒时后端回人话警告，前端以 `err` 类 Toast 转达（含手动添加所需的 `127.0.0.1 {domain}`），不阻断；请求在途期间按钮禁用（提权弹窗可能停在系统侧）。`Hosts` 列翻转只等 `state:changed` 回流，无本地乐观更新（硬红线 4）。

### 5.1 可自定义根的路径条（`EditablePathBar.vue`，AGENTS.md §5.15）

缓存根与备份根用同一个组件 `components/common/EditablePathBar.vue`，它把「当前生效值 + 编辑 + 选目录 + 保存 + 恢复默认」收进一条：

> **权威口径（用户裁决，AGENTS.md §5.15.1 / §0.3「同类路径生效根数」/ 决策 23）**：**三处可自定义根——缓存根、备份根、每服务版本数据目录——各自「自定义与默认互斥唯一，任一时刻永远只有一个生效值」**。自定义一旦设定即**完全取代**对应默认根（`./offline/` · `./backups/` · `{KIND_ROOT}/{version}/data`），置空（或点「恢复默认」）即回落默认；界面**不把默认值与自定义值并列展示**、不出现「两处都用」的状态，路径条显示的永远是当前唯一生效的那一条。数据目录的入口是安装弹窗的输入框 + 目录选择器（见下方末条），回显走挂载表的 `{KIND}_{VER}_DATA_DIR`。

| 元素 | 行为 |
|------|------|
| 输入框 | 初值 = 快照 `env` 的 `OFFLINE_ROOT` / `BACKUP_ROOT`（已展开 `~`），**只显示当前生效的那一个**，默认值与自定义值不并列；`placeholder` 给默认根作为「恢复默认后会是什么」的提示 |
| 「已自定义」标记 | `isCustom = path !== defaultPath`——判据是**值相等**，不另存布尔位；为真时右侧挂 `root.custom` chip 并露出「恢复默认」按钮 |
| 保存 | 显式按钮 `root.save`，`dirty`（去尾斜杠后与生效值不同）且非在途才可点；提交即 `emit('save', v)` → `setOfflineRoot` / `setBackupRoot`。**空串不放行**（回滚输入框），回落默认走「恢复默认」按钮（`emit('reset')` → 后端写空值） |
| 浏览 | `Dialogs.OpenFile({ CanChooseDirectories: true, CanChooseFiles: false })` 选目录，去尾斜杠后回填输入框（仍需点「保存」才落库）；宿主不可用时按钮**不渲染**（`v-if="canBrowse"`），而非静默失效 |
| 回流 | 视图层 `await` 后端返回后 `syncState()`，新根由 `state:changed` 快照回显，**不做本地乐观改写**（硬红线 4）；在途期间 `saving` 禁用按钮 |

- 落点：`OfflineView.vue`（缓存根，需求 1）、`BackupView.vue`（备份根，需求 8）。
- **每服务版本的数据目录**（需求 7）不走这条：它是**安装时**的选填项，落在 `InstallModal.vue`（输入框 + `svc.dataDirBrowse` 目录选择器，`placeholder` = `defaultDataDir(kind, version)`），安装成功后经 `setServiceDataDir` 落 `config.yaml`；改已装服务的目录要走重装，故安装弹窗是唯一入口。数据服务页的挂载表（`MountList.vue` + `constants/mounts.ts`）按 `{KIND}_{VER}_DATA_DIR` 回显生效值。**同样互斥唯一**：填了自定义目录，默认的 `{KIND_ROOT}/{ver}/data` **不再凭空创建**（`workdir.prepareService` 跳过），容器挂载点直接指向自定义目录（§5.15.1）。
- `OfflineView.vue` 原 `.off-events`「实时缓存事件」面板**已删除**（§5.6.2）：`cache:*` / `docker:*` 事件统一进日志抽屉的实时通道，不再在同一页维护第二份事件列表。

### 5.2 PHP 扩展选择器（`ExtPicker.vue`，AGENTS.md §5.16）

两处入口共用**同一份全量目录**（`frontend/src/constants/ext.ts`，73 项 / 8 分组），不再各维护一份裁剪清单：

| 入口 | 判据与默认值 | 提交 |
|------|-------------|------|
| `InstallModal.vue`（安装 PHP） | 仅 `kind === 'php'` 显示扩展区，弹窗宽度转 `lg`；默认勾选 = `commonExts(version)`（11 项常用）；**一项都不选即只装基座镜像** | 安装任务之后串**第二个任务**跑 `applyExtensions`（扩展是「容器内编译 → 固化镜像 → 重建」另一条链路） |
| `PhpExtensionsModal.vue`（PHP 列表页「管理扩展」） | 默认勾选 = **本版本当前已应用的扩展**（安装时勾的 + 之后改过的）；`dirty` 判据是集合与原始勾选不等 | `preflight('extensions')` → `applyExtensions` → `syncState()`；扩展列表**写后拉权威快照归位**，不做本地乐观更新（硬红线 4） |

- `ExtPicker.vue`（`components/common/`）：按分组渲染 chips，点击即勾选/取消；顶部有过滤框、「勾选常用」「清空选择」、`{count} / {total} 已选` 计数；分组顺序即 `EXT_GROUPS`（基础 / 数据库 / 缓存 · 序列化 / 图像 · 文档 / 网络 · 消息 / 异步 · 高性能 / 框架 C 实现 / 调试）。
- **目录外可扩展**：手输扩展名（格式过 `ValidateExt`，即 `^[a-zA-Z0-9._-]+$`）即入列并选中——目录是便利集不是白名单（最小限制原则，§0.2 规则 15）。
- **失败即不关窗**：`submitWrite` 把后端短消息（含扩展名与「本次扩展集未应用」）原样 toast，弹窗保持打开，用户改一项即可重试；编译期该扩展的 stdout/stderr **逐行**进抽屉日志（§5.16.3）。
- 版本可见性由 `minVer` 决定（`ffi` ≥ 7.4、`sodium` ≥ 7.2）；版本号非数字（用户自定义标签）时不做限制，交后端路径安全裁决。

## 6. 命令面板 / 托盘 / 日志抽屉

- `CmdPalette.vue`：`CMD_ITEMS` **20** 条命令（§0.3）。
- `AppTrayMenu.vue` + `internal/ui/tray.go`/`menu.go`：原生托盘；`ui:command` 本地广播联动（不属于 17 协议事件）。
  - **设置页「托盘」两张开关是真开关**：`prefsStore` 在宿主就绪后（`App.vue` 的 `waitForBackend()` 之后）经 `api/state.ts#setTrayPrefs → App.SetTrayPrefs` 投影到原生外壳，此后勾选变化由 `watchEffect` 自动跟随；纯 Vite demo 无宿主时跳过，只驱动窗口内的 `AppTrayMenu.vue` 仿真。`localStorage` 仍是权威，后端不反向读取（§3.1 原则 5）。
  - **关闭窗口（X）的落地行为**：两项开关同时为真 → 隐藏窗口驻留托盘（点托盘图标唤回，`AttachWindow` 后 `ToggleWindow` 才有效）；否则 → 退出进程。裁决函数 `resideOnClose()`（`internal/ui/tray.go`），Linux 撤图标是平台空操作、但裁决照常生效（见 `跨平台差异.md` §5）。
  - **「退出 phpo」两个入口一个出口**：原生托盘菜单（`menu.go`）只广播 `ui:command(quit)`，**不**自己调 `app.Quit()`；退出统一由 `AppTrayMenu.vue#quitApp` 裁决——`task.queueRunning` 为真则 `TASK_BUSY` toast 拒退（原先用 `window.alert`，webview 里不保证可见），否则经 `api/state.ts#quitApp → App.Quit()` 退出进程。这样原生入口不会绕过忙锁，也不会两路并发终止撞在 Wails 主线程上；**Linux 无 libappindicator 时窗口内托盘是唯一退出入口，它必须真的能退**。纯 Vite demo 无宿主 → `quitApp` 先行 return，浏览器里没有可退出的进程。
- `TaskDrawer.vue`：订阅 `task:log/progress/done`，按 5 类日志行渲染；`等效命令`（`.drawer-cmd`）保留展示但标注「仅展示」、不可执行，复制时 Toast「本产品不提供 CLI」（§1.4）。
  - **头部左侧标签固定「服务」二字**（需求 5）：`.drawer-label` 恒取 `t('nav.services')`，**不随当前路由改名**——抽屉是全局的，任务运行时也要一眼认出它在哪。其余元素（服务运行点灯、等效命令、进度 chip、状态文字、三个按钮）不变。
  - **左右两栏布局**（AGENTS.md §5.6.1）：`.drawer-body` 内左栏 `.drawer-main`（进度条 / 失败原因 / 日志流）**默认 70%**，右栏 `.drawer-queue`（任务队列）**默认 30%**，两栏各自 `overflow:auto` 独立滚动。
  - **中缝可左右拖拽**（需求 4）：`.drawer-splitter`（宽 7px，`margin:0 -3px` 压在两栏接缝上、`cursor:col-resize`）`@pointerdown` 起拖、`@dblclick` 复位 70%。占比走 `layoutStore.setSplit()`，夹取区间 **40–80**（`LAYOUT_LIMITS.split`），落 `localStorage` 键 `phpo-drawer-split`，经 CSS 变量 `--drawer-split` 驱动两栏 `flex-basis`；**属 UI 偏好不落库**（§3.1 原则 5），故 70/30 是默认值而非固定值。
  - **系统日志通道**（需求 3/6，§5.6.2）：无运行任务时 `cache:*` / `docker:*` / `update:*` 事件逐行进左栏（**`update:progress` 是唯一豁免**——它是连续量，已由升级弹窗进度条承载），空态标题取 `task.sysEmpty`；一旦有任务在跑，同一事件回归该任务的日志流（`eventLine()` 按 `app.tasks.running?.id` 分流）。上限 `SYS_MAX=200` 行裁尾，**不建任务记录、不落账本、不新增事件名**。
  - **队列区**（`.drawer-queue`）是**竖排列表**（不再是 chip 流），一行 = 状态点 `.dq-dot` · 标签 · `step/total` · 显示态文字 · 「撤回」按钮；**新提交的任务永远在最上面**（记录池本身 newest-first，运行中任务不因开始执行而下移，行位只随提交先后决定）。
  - **显示态由 `taskStore.ts#displayOf` 从权威快照派生**（`waiting`=等待中 / `running`=执行中 / `done`=已完成 / `failed`=失败 / `cancelled`=已取消 / `unknown`=状态未知兜底），**后端任务状态仍是 4 个、事件名仍是 17 个**，第 5 态不新增；`unknown` 只在后端新增终态未经映射时兜底，预留扩展位。队列行仅 `waiting` 项显「撤回」（`App.CancelQueued`），撤回命中后该行随下一次快照消失。
  - **即时同步 + 不留幽灵选中**：`syncBoard` 为 `Running` **和每一个 `Pending` 项**都建/更新记录（排队项无日志，左栏给空态提示）；若被撤回项正被选中，选中在同一次快照里回落到运行中任务，不显示「状态未知」的残留详情。全程无本地乐观插入、不靠「从队列消失」推断终态（硬红线 4）。
  - **进度条**（`.drawer-progress`）由 `step/total` 驱动；运行中只显示在途步骤，**不提前显示失败**。
  - **失败原因**（`.drawer-error`）仅在 `task:done(status=failed)` 后出现，正文是该任务最后一条 `err` 级日志原文；成功侧显示「完成 · X.Xs」（ns 换算）。
  - **历史任务**走 `api/task.ts#listTaskHistory` → `operations` 表带 `task_id` 的行（含终态、耗时、失败原因、尾部日志），跨重启可回看。
  - `submitWrite()`（`composables/useTask.ts`）是所有写操作的前端入口：登记等效命令 + 立即展开抽屉，再发后端调用；后端当场拒绝（`ErrQueued`/`ErrBusy`）以 Toast 上抛，状态一律由事件回流（硬红线 4）。

## 7. 主题 / 缩放 / i18n（纯前端）

- 6 主题（`styles/themes/`：light/dark 对应 `midnight`/`ocean`/`forest`/`sakura`/`oled` + `index.css` 汇总），由 `prefsStore` 切换，落 `localStorage`（§3.1-5）。
- `UI_SCALE` 7 档位缩放 + `useZoom`/`useResize` 补偿；`layoutStore` 管布局。
- i18n：`locales/zh-CN.ts` + `en-US.ts`（约 300+ 键，从原型 `MESSAGES` 提取），`scripts/check-i18n-keys.go` 对齐校验。后端另有 `pkg/errs` code → 前端 i18n 文案（错误信息是人话，§3.2 原则 3）。

## 8. 状态回流

前端只读 `appState` store（由 `useStateSync` 订阅 `state:changed` 写入），组件不各自订阅、不乐观更新（硬红线 4）。UI 偏好（主题/语言/布局/缩放）例外，留在前端 `localStorage`。
